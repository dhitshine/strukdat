# Data Structure Archives

This repository contains an archive of exercises, assignments, and practical exam solutions for the Data Structure (Struktur Data) course at ITS (Institut Teknologi Sepuluh Nopember).

## Repository Contents

The repository is organized into three main directories:

### 1. Homework Assignments (tugas)
This directory contains weekly homework assignments assigned by the course lecturer. They are implemented in C and C++.
- **tugas-1**: Basic C programming exercises using structs, pointers, and memory manipulation.
- **tugas-2**: C programming exercises focusing on array operations, pointer manipulation, and memory management.
- **tugas-3**: Implementations and operations on Doubly Linked Lists in C++.
- **tugas-4**: Queue and Priority Queue data structure implementations in C++.
- **tugas-5**: Linked list validation, operations, and sorting routines in C++.
- **tugas-6**: Binary Search Tree (BST) operations, including node insertion, search, and height calculations in C++.
- **tugas-7**: AVL Tree self-balancing implementations and tree rotations in C++.

### 2. Practical Exams (praktikum)
This directory contains solutions for the hands-on practical coding exams (Praktikum) conducted throughout the semester. These problems are solved under competitive programming constraints (such as time limit and memory limit) using C++.
- **praktikum-1**: Basic linear data structure challenges (such as arrays, stacks, and queues).
- **praktikum-2**: Intermediate data structure challenges (such as linked lists and binary trees).
- **praktikum-3**: Advanced data structure challenges (such as self-balancing trees and custom graphs).
- **praktikum-final**: Comprehensive collection of problems covering all topics discussed in the course.

### 3. Lab Exercises (lab)
This directory contains helper templates and tasks completed during laboratory practice sessions to reinforce core concepts.
- **lab2**: Operations on trees, BST insertion, searching, and depth/height metrics.
- **lab3**: Advanced tree and graph structures.
